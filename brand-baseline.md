1. Open **brand-baseline-prompt.md**.
2. Run it in Claude — Claude Code pointed at this folder (so it can read your files),
   or claude.ai with your assets attached.

4. Commit it.

about your brand sharpens, you edit this file in place and commit the change — git keeps
every version, so you never lose the past and you never start over.

reads from it first.
